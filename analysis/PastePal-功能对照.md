# PastePal 功能对照与 XPastepal 实现范围

日期：2026-10-14（Asia/Taipei）。对照对象为本机 PastePal 2.19.6（214）；XPastepal 包名为 `milu.pastepal`。

## 证据范围

1. **本机应用包的只读证据**：沿用 [静态分析](PastePal-静态分析.md) 中的 Info.plist、Mach-O 依赖、CoreData 模型、资源 bundle 和本地化键。本轮额外只读检索 `/Applications/PastePal.app/Contents/Resources/en.lproj/Localizable.strings`，确认集合、预览、范围选择、键盘导航、文本转换、导入导出等功能语义。资源中的文案说明该功能存在于产品中，不足以确认当前运行状态或具体页面布局。
2. **官方文档**：阅读 [Mac 快速开始](https://docs.indiegoodies.com/pastepal/Mac/quick-start)、[快捷键](https://docs.indiegoodies.com/pastepal/Mac/features/keyboard-shortcut)、[导出](https://docs.indiegoodies.com/pastepal/Mac/features/export)、[图片文字识别](https://docs.indiegoodies.com/pastepal/Mac/features/recognize-text-image)、[文本转换](https://docs.indiegoodies.com/pastepal/Mac/features/transform)。这些文档说明产品公开设计，不能替代本机 2.19.6 的逐项运行验证。
3. **现场界面的限制**：本轮原 PastePal 进程正常，但两次 CUA 绑定超时，未取得可操作的普通窗口。因此没有完成本机原版与 XPastepal 的并排像素比对，不声称字体、间距、动画或所有菜单一致。

未读取原 PastePal 的历史、账号或应用容器；未导入原程序代码、图标、音效或整包字符串。XPastepal 使用自己的数据结构、系统符号和独立 Swift 实现。

| 文本编辑与新增 | 本机 Insert、内容预览语义 | 详情编辑现有文本；新增文本；转换结果预览、复制 | 未提供标签命名、模板变量 |

## 快捷面板与快捷键

- 使用 KeyboardShortcuts 3.1.0 统一注册全局快捷键，移除重复菜单快捷键入口。支持原生录制、清除、恢复默认、持久化、旧版偏好迁移、冲突提示和重试。
- 面板在鼠标所在屏幕呼出，可停靠上/下/左/右，保持展开，拖动左上标题区域，调整卡片宽度，选择仅复制或默认纯文本。默认纯文本仅影响文字和链接，图片/文件保留原类型。
- 面板支持集合和类型筛选、方向键、Tab 切换搜索焦点、Enter / Shift+Enter、Cmd+1…9、Cmd+[ / Cmd+]、Cmd/Shift 多选和空格预览。
- 中文输入法组合输入期间由系统处理候选确认和方向键。Shift 选择支持向回缩减范围。
- 用户于本轮实体键盘验证自定义 `⌃⌥⌘P` 可以从其他应用呼出；重启后录制值保留。验收结束恢复原组合 `⌃⇧V`。CUA 定向注入按键不作为 Carbon 全局事件分发的通过证据。

- 粘贴队列：10 秒内连续复制自动排队（中间粘贴过则不排队），剪贴板保持队首；通过辅助功能全局按键监听识别其他应用中的 `⌘V`，松开 V 后切换到下一条，取空恢复正常。排队、前进、重置和跳过已删除条目由 `PasteQueueTests` 覆盖。

## 验收入口

资料库新功能集中在 `LibraryView.swift`、`LibrarySupportingViews.swift` 和 `LibraryClipDetailView.swift`。本轮完整 `swift test` 23 项通过，release 构建与签名校验通过。桌面验收覆盖录制框、自定义组合重启保留、面板导航、Shift 选择缩减与空格预览；用户确认真实全局快捷键可呼出。

可使用本次任务自建的测试内容验证：复制文字后按方向键选择，⇧ 或 ⌘ 多选，回车合并复制；右键移集合并重命名；空格打开预览；在文本框中输入空格/回车确保未被资料库快捷键拦截；导出 JSON 后重复导入确认合并不重复；对测试图片运行 OCR 并保存识别结果。
